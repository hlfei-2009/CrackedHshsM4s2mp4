一款破解版 秒转M4S，原开发者是 忽闪忽闪（深圳）科技有限责任公司。但已由 hlfei-2009 破解并深度魔改！主要破解并深度魔改的内容有：去除的其所有广告、引入了横屏和深色主题支持，详情请参阅此应用的《用户协议》、《隐私政策》和《免责声明》。虽说这是基于旧版 1.5.1 破解并深度魔改的，但有一个最新版没有的优点：例如您使用 MT管理器 将 m4s 文件从 哔哩哔哩 的视频缓存目录复制/移动到系统媒体库可扫描的目录，那么系统媒体库不会立即扫描，这时最新版的 秒转M4S 是无法识别到相应的 m4s 文件的，因为它只能利用系统媒体库识别文件，这会带来麻烦。但是这个破解并深度魔改版的此应用却可以不利用系统媒体库识别文件，只要您使用此应用处理文件时选择“从内部存储选择”选项

此应用的宣传描述：秒转M4S 是一款面向本地文件的 M4S 处理工具。你可以在设备上扫描或选择 .m4s 文件，配对同一组 audio.m4s 与 video.m4s，并导出为标准 MP4。处理过程在手机本地完成，不上传用户的视频或音频文件。
